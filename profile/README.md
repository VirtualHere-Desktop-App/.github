## 👁️ At a Glance
VirtualHere for Windows is a fast, dependable USB-over-IP solution. The VirtualHere USB server shares a device from the PC it is attached to, and the client uses it from anywhere on the network as if it were plugged in locally. It is ideal for dongles, printers, scanners, and instruments, works over LAN or the internet, and needs no special hardware. Trusted by teams and hobbyists alike, many consider it the best USB-over-IP solution for a Windows PC.

## 🎁 What You Get
| Feature | What it does for you |
|---------|----------------------|
| USB server | Shares a device from the PC it is plugged into. |
| USB client | Uses a shared device on a remote PC as if local. |
| Dongle sharing | Puts license dongles on the network for a team. |
| LAN or internet | Reaches devices nearby or far away. |
| Wide support | Works with printers, scanners, cameras, and more. |

## 📥 Install Guide
1. Click the **Download** button above to get VirtualHere for Windows.
2. Install the USB server on the device PC and the client on the remote PC.
3. Launch VirtualHere and confirm devices appear.

## ⚡ Quick Start
1. Run the USB server where the device is attached.
2. Open the client on the other PC.
3. Find the shared device.
4. Connect to it.
5. Use it as if it were local.

**Which versions of Windows are supported?**
